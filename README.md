# Heart-Sound-Demo

## Deployment (free tier)

| Part | Host | Config |
|---|---|---|
| Website (React/Vite) | Vercel, root directory `frontend` | `frontend/vercel.json` — serves the SPA and forwards `/api/*` to the backend, so login cookies are same-site |
| API (Node/Express + heart sound model) | Render free web service | `render.yaml` (Blueprint) |
| Database | MongoDB Atlas M0 | `DB_URL` |
| Email (OTP) | Brevo HTTP API (Render's free tier blocks SMTP) | `BREVO_API_KEY`, `EMAIL_FROM` |

The backend runs the heart sound model in-process with TensorFlow.js — same pipeline and model as `ai-service/` (verified
against it), so no Python service is needed. After changing the website's inference code or model, run
`backend/scripts/sync-inference.sh` to regenerate the backend copy.

Render env vars to set in the dashboard: `DB_URL`, `BREVO_API_KEY`, `EMAIL_FROM`, `ALLOWED_ORIGINS` (the Vercel URL).
JWT secrets are generated by Render.
